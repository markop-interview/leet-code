# Medior

Current track. About 150 tasks that follow the NeetCode 150 patterns, in strictly increasing difficulty from Task #001. The aim is idiomatic Go under interview conditions: a solution you can write on a whiteboard, an early return when the answer is known, and a time and space trade-off you can explain.

Cards are on [Go Interview Prep - Medior](https://trello.com/b/A0jOhpzi/go-interview-prep-medior). Workflow, grading, and local checks are in the [repo README](../README.md).

## Patterns

- Arrays & Hashing
- Two Pointers
- Sliding Window
- Stack
- Binary Search
- Linked Lists
- Trees
- Tries
- Heap
- Backtracking
- Graphs
- 1-D DP
- Intervals
- Greedy
- Bit Manipulation
